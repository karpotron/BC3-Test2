
BC3 Reader - Web PWA (Improved Parser)
======================================

Archivos incluidos:
- index.html
- app_improved.js
- style.css
- manifest.json
- icon-192.png
- icon-512.png
- README.txt

Notas:
- Este parser preserva el orden original del fichero BC3 y construye la jerarquía de títulos (~T) respetando el orden.
- Asocia las partidas (~C) con el título más adecuado buscando coincidencias exactas, prefijos largos y prefijos numéricos.
- Extrae mediciones (~M) y calcula cantidades totales heurísticamente, evaluando expresiones sencillas.
- Export CSV desde la vista de capítulo para revisar partidas y totales.

Sigue las instrucciones del chat para subir a GitHub Pages (index.html en la raíz).
